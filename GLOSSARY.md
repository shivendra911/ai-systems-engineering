# Glossary

A small shared vocabulary makes the rest of the course easier to follow.

## Starter terms

- AI: Systems that perform tasks normally associated with human intelligence.
- ML: A subset of AI where systems learn patterns from data.
- DL: Machine learning based on neural networks with many layers.
- Foundation model: A large pre-trained model that can be adapted to many tasks.
- LLM: A language model trained to work with text and text-like sequences.
- Embedding: A numerical representation of meaning.
- Token: A chunk of text used by a model.
- RAG: Retrieval-augmented generation, where retrieval helps the model answer.
- Agent: A system that can decide on actions and use tools.

## How to use this file

- Keep definitions short.
- Prefer the meaning used in this course, not just a dictionary definition.
- Add new terms as soon as they appear in a chapter.
