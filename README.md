# AI Systems Engineering

This repository is a long-form course and build log for learning how modern AI systems are designed, implemented, and operated.

The idea is simple: each volume teaches a layer of the system, and each important concept should eventually be built in code, not just described.

## How the course is organized

- `Volume 1` explains the landscape: models, products, and system architecture.
- `Volume 2` explains how models work internally.
- `Volume 3` explains APIs and communication.
- `Volume 4` covers the building blocks used inside AI apps.
- `Volumes 5 to 8` move into services, infrastructure, product engineering, and production operations.
- `Volume 9` studies real systems using public information.
- `Volume 10` combines everything into one platform.

## Teaching style

Each chapter should stay connected to the bigger system. A topic should answer not only what it is, but also where it fits, how it behaves, how it fails, and how it is shipped in production.

## Repository layout

- `volumes/` contains the teaching path.
- `projects/` contains the practical builds.
- `diagrams/` stores architecture and flow diagrams.
- `code/` holds supporting snippets and experiments.
- `retrospectives/` captures lessons from completed work.
- `assets/` stores images and other reference material.
