# Learning Log

Use this file as a simple running notebook for what changed, what was learned, and what still feels unclear.

## Entry format

- Date
- Volume / chapter
- What was learned
- What was built
- What was confusing
- What to revisit next

## Notes

- Keep entries short and factual.
- Record ideas while they are still fresh.
- If a lesson changes a design decision, write that down here.
- Use this file to connect theory to implementation.
